## 3 Recommended Niches

| # | Niche | Brand | Market Size | Best For |

| 1 | Outdoor & Backyard Life | ALFRESCO CO. | $1B+ USD | High AOV, summer season |

Each niche has 3 products solving **different problems** (not complementary bundles).

## Tech Stack

- **Store:** Next.js + React (custom, no Shopify)
- **Payments:** Stripe Australia
- **Language:** Australian English
- **Suppliers:** CJ Dropshipping AU, Dropshipzone, Factory Fast
- **Budget:** $500 USD execution plan included

## Top Pick

**WAGWELL** — Pet Owner Essentials
- 69% of AU households own a pet
- 70–80% gross margins
- 2–5% return rate
- 3 problems: pet hair / boredom destruction / car travel mess
