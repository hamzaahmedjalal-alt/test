# نما بيوتي — Nama Beauty Store

متجر Next.js للعناية والجمال — عربي RTL — COD.

**النطاق:** [namabeauty.shop](https://namabeauty.shop)

## المنتجات

| المنتج | المشكلة | النوع |
|--------|---------|-------|
| **نما ستيلر برو** | شعر ما يثبت بالحر | أداة تصفيف 5-in-1 |
| **نما ميست** | العطر يختفي بالحر | عطر شعر وجسم |
| **نما جلو** | مسام وبشرة باهتة | جهاز تنظيف بشرة LED |

## التشغيل

```bash
npm install
cp .env.example .env.local
npm run dev
```
