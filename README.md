# Ember & Oak — Restaurant Website

A modern, responsive single-page website for a fictional fine-dining restaurant.

## Features

- Full-screen hero with call-to-action
- About section with stats
- Tabbed menu (starters, mains, desserts, drinks)
- Photo gallery
- Reservation form with validation
- Mobile-friendly navigation
- Smooth scroll animations

## Getting Started

Open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Structure

```
├── index.html      # Main page
├── css/
│   └── styles.css  # All styles
└── js/
    └── main.js     # Navigation, menu tabs, form handling
```
